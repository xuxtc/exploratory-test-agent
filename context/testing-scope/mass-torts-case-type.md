# Mass Torts: Case Type Selection

## When this rule applies

Any time the executor needs to create a new case with **Practice Area = Mass Torts** during a test run (via `/create-case` or directly through the Portal UI).

## What it controls

Select **NEC** as the case type when creating a Mass Torts case.

## Rationale

NEC is the designated case type for Mass Torts test cases. Choosing a different type may result in a different form layout or required fields, causing the test to diverge from the intended scenario.
